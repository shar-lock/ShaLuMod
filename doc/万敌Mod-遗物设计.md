> **项目**：Slay the Spire 2 角色模组「万敌（Mydei）」

## 一、设计原则

1. **灵魂遗物先行**：起手遗物「弑亲血脉」合并原方案的**血仇引擎 + 弑亲血脉免死**二为一——它是整个角色的引擎与安全网，让万敌「一上来就玩得像万敌」。
2. **强度随稀有度递增**：普通=被动收益件 / 罕见=流派构建件 / 稀有=核心引擎与终结 / 商店=机制联动件（对标罕见强度；Shop 稀有度只在商店出售，不进掉落池）。每档 1 件。
3. **核心循环闭环**：5 件遗物都围绕「血仇 + 纷争 + 生命经济」主轴——起手产血仇并生成荡平万邦，普通/罕见从「失血 / 回血」双通道加血仇（纷争的等量回血天然落在回血通道上），稀有提供击杀续航（按含纷争上限结算），觉醒强化血仇与荡平万邦，逐档把循环推到高潮。
4. **符合原著**：致敬崩铁「万敌」——毁灭命途、虚数金、血量即资源、天赋级不死、弑神状态。
5. **觉醒=起手的「完全体」**：经游戏自带的先古之民**欧洛巴斯**（拾得「欧洛巴斯之触」时）替换起手遗物；既加数值，也加新机制。

## 三、起手遗物「弑亲血脉」（核心合并）

把设计方案里的 **血仇（Vengeance）Power** 与 **弑亲血脉（4 次免死）** 合并为一件起手遗物。

> **为什么要合并**：血仇是万敌全卡组的资源中枢（誓约之枪 / 蓄势 / 蓄血 / 复仇心 / 弑王枪连突… 都读写它）。若血仇只能靠「力敌万邦」形态牌获得，玩家前几层根本凑不出引擎。让**起手遗物自带血仇引擎**，角色从第一场战斗就是万敌；而「力敌万邦」形态牌的价值变成「加速血仇引擎（回合 +2 血仇 + 获得血仇时抽牌）」，二者职责分离、互不抢戏。

| 项               | 内容                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                            |
| ---------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **名称**   | 弑亲血脉 / Blood of the Kinslayer ⭐                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                            |
| **稀有度** | Starter（起手）                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                 |
| **流派**   | 免死 + 血仇引擎（角色灵魂）                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                     |
| **效果**   | ① 战斗开始时，获得「血仇」Power（初始 1 层 = 储备，显示为空、0% 增伤）。<br />② 每当失去生命（自伤 / 受击，任意来源）→ +1 血仇。**成长型触发**：每累积 7 层（首次到 8 层 / 玩家视角 7 层）消耗 4 层（不清空，触发基准逐次抬高 → 触发点 8→11→14…，血仇逐轮成长 +3/轮）、扣除当前血量 5%（至少 1），将一张「荡平万邦」加入手牌（觉醒遗物「不灭王血」在场时给升级版）。状态栏血仇显示 = 真实层数 − 1。<br />③ **免死（4 次充能）**：生命值将降至 0 时，免疫死亡，改为回复至 30% 最大生命，消耗 1 次充能（共 4 次）。遗物计数器显示剩余次数。实现套用游戏遗物「蜥蜴尾巴 / Lizard Tail」的免死逻辑。 |
| **致意**   | 万敌的弑亲之罪 + 克雷莫诺斯人不死诅咒——他既杀不死，也死不掉。4 次充能致敬星铁天赋「4 次免死」。                                                                                                                                                                                                                                                                                                                                                                                                                                                               |

> **与【纷争】的结算口径**（v3 新增）：
> - 免死回复「30% 最大生命」按**当前（含纷争）最大生命**结算——纷争越高，免死回血越多（游戏原生 `creature.MaxHp` 语义，无需特判）。
> - 每次「获得纷争」都是一次**回血事件**（抬上限 + 等量回血）→ 会触发焚血勋章（回血 → +1 血仇）。纷争流因此也是血仇的二号引擎。
> - 纷争在战斗结束时清空还原——免死充能、血仇层数不受影响（它们本就跨战斗保留/清空按各自规则）。

### 血仇 Power：能做什么

血仇（Vengeance）= `Buff` + `Counter` 计数型 Power。它**不是**纯计数器——层数本身有两类作用：

1. **伤害放大器（被动）**：每层血仇使你的**攻击牌**伤害 **+2%**。失血越多、攻击越狠——这是万敌「越痛越强」的进攻节奏，让起手遗物即便没抽到特定卡牌，攒层也有立竿见影的收益。
2. **卡牌资源**：血仇同时是许多卡牌的燃料——

   - 按层数缩放伤害：`噬仇`（血仇×3 伤）、`狂怒`（造成血仇层数伤）；
   - 消耗层数增伤：`弑王枪·连突`（每段消耗 1 层 +3 伤）、`血祭仪典`；
   - 一次性吞噬爆发：`诛天焚骨的王座`（吞所有血仇，每层全体 8 伤）。

   详见 [卡牌设计稿](万敌Mod-卡牌设计.md)。

> **存与费的抉择**：正因为有被动加成，消耗血仇的卡牌要权衡「现在爆发」还是「保留层数吃 +2%/层」——这是万敌的核心决策张力，避免血仇沦为无脑消耗的数字。

> **形态牌的定位**：「力敌万邦」（原纷争形态）是血仇引擎的**加速件**——回合开始额外 +2 血仇、获得血仇时抽牌（每回合 ≤2），让血仇更快积攒、更早触发荡平万邦。它**不提供额外增伤**（增伤完全由基础 Power 的 +2%/有效层覆盖），与基础被动不冲突。

> **决策记录（已定方案 A）**：血仇基础 Power 保留 **+2%/有效层攻击伤害**的内在被动（有效层 = 真实层 − 1，保底 1 层无增伤）。曾考虑纯资源方案（无被动），因起手遗物自洽性更佳、角色进攻节奏更顺而采纳 A。「力敌万邦」形态牌不再提供 +25% 强化态，改为加速产层 + 抽牌（与 [卡牌设计稿](万敌Mod-卡牌设计.md) 一致）。

### 对局外掉血的处理（未实装 · 已豁免）

> **当前实现**：血仇只在**战斗内**叠层（Power 的失血回调 `AfterDamageReceived`，每次掉血事件 +1，非每点生命 +1）。**对局外掉血（地图事件 / 献祭等）的遗物桥接未实装**——原设计是遗物暂存对局外失血、下场战斗开始时一次性转化（上限 3），但当前代码采用「兜底：忽略对局外掉血」的最简退路，核心循环不受影响。若后续要补，见 [log/TODO.md](../log/TODO.md)。

## 四、池中遗物（4 件：普通/罕见/稀有/商店各 1 件）

### 普通

| 遗物（中 / 英）               | 效果                                                  | 流派       |
| ----------------------------- | ----------------------------------------------------- | ---------- |
| 沾血枪尖 / Bloodied Spearhead | 每当你因**打出的卡牌**失去生命，获得 1 层血仇。 | 烧血·增益 |

> 简单被动收益件——任何烧血牌都顺手触发，把卖血直接折现成血仇资源，不需要特定 build。数值起点，待平衡。
>
> **触发口径**：沾血枪尖限定「因**打出的卡牌**失血」才触发（奖励主动烧血）；起手遗物的血仇引擎是「任意来源失血」（受击也算）。这是有意的区分——挨打由起手遗物叠血仇，主动烧血则额外触发沾血枪尖再叠一层，让卖血卡越打血仇涨得越快。

### 罕见

| 遗物（中 / 英）             | 效果                          | 流派       |
| --------------------------- | ----------------------------- | ---------- |
| 焚血勋章 / Bloodburn Emblem | 每当你回复生命值，获得 1 层血仇 | 回血·血仇 |

> 回血也要折现成血仇——把涅槃 / 饮血反击 / 不死王权 / **纷争获得**等回血效果二次转化为血仇资源。和沾血枪尖（失血→血仇）形成「失血 / 回血双通道产血仇」，让血仇引擎转得更猛。**纷争流拿到它等于白捡一座血仇引擎**——每次抬临时上限都 +1 血仇。

### 稀有

| 遗物（中 / 英）               | 效果                                     | 流派       |
| ----------------------------- | ---------------------------------------- | ---------- |
| 血仇圣坛 / Altar of Vengeance | 敌方单位死亡后恢复 2% 最大生命值的血量。 | 回血·续航 |

> 卖血流的关键续航——万敌靠自伤压血线进攻，血仇圣坛把「击杀」转化成按最大生命比例回血，把卖血亏掉的血量在清场时补回来，让「敢卖血」真正可持续。和「毁灭裁决」「噬魂」等斩杀卡配合回血最猛。**结算按含纷争的当前最大生命**——纷争堆得越高，击杀回得越多，是纷争流的续航放大器。

### 商店

| --------------------------- | ------------------------------------------------- | ---------- |
| 深红契印 / Crimson Sigil    | 战斗开始时，获得 1 张荡平万邦。（持有不灭王血时获得升级版） | 荡平万邦·终结 |

> 商店档补位（v6 再重设；v4 经济向、v5 卖血产层两版均已迭代——商店遗物应服务角色机制而非金钱，且描述只写主效果）。Shop 稀有度只在商店出售、不进掉落池；强度对标罕见遗物：直接发一张血仇引擎的终结技，让「荡平万邦流」开局就有终结手段，也是泛用 0 费 AoE 终结件；持有觉醒遗物「不灭王血」时自动升级为强化版（与血仇 Power 触发的觉醒判定同款）。实现：弑亲血脉同款 `BeforeCombatStart` 钩 + `CombatState.CreateCard` 造可变实例（规范实例进手牌会抛 CanonicalModelException）+ `CardCmd.Upgrade` 就地升级 + 悬停预览荡平万邦。

## 八、实现备注（M2 / M3 实装用）

### 命名 / 资源约定

- 遗物类名 = 英文名 PascalCase，如 `Blood of the Kinslayer` → `BloodOfTheKinslayer`。
- 图标资源 = **类名小写**（见 [WandiModRelic.cs](../WandiMod/WandiModCode/Relics/WandiModRelic.cs) 的 `Id.Entry.RemovePrefix().ToLowerInvariant()` 约定），如 `BloodOfTheKinslayer` → `bloodofthekinslayer.png`，放 `WandiMod/images/relics/` 与 `big/`，外加 `_outline.png`。
- 缺图自动回退 `relic.png` / `relic_outline.png` 占位（M2 先用占位，M4 替换）。

### 依赖与钩子

- **「血仇」Power 是 M2 交付物**，本组所有遗物都依赖它已存在。
- 遗物 / Power 行为钩子来自游戏 `sts2.dll`（BaseLib 的 `CustomRelicModel` / `CustomPowerModel` 薄封装）。**均已反编译确认并实装**：
  - **失血回调 `AfterDamageReceived`**：血仇引擎（任意来源失血 → +1 血仇，参考 RupturePower）；沾血枪尖（仅 `cardSource != null`，即因打出的卡牌失血）；焚血勋章走 Harmony Postfix on `CreatureCmd.Heal`（无原生 AfterHeal 钩子）。
  - **伤害放大 `ModifyDamageMultiplicative`**：血仇 +2%/有效层（有效层=真实−1，参考 WeakPower）。
  - **回合/死亡钩子**：不灭王血 `AfterSideTurnStart`（每回合 +1 血仇）；血仇圣坛 `AfterDeath`（敌方死亡回 2% MaxHp）。
  - **免死**：`ShouldDieLate` + `AfterPreventingDeath`（参考 LizardTail），改为回复 30% MaxHp + 消耗 1 充能（共 4 次）。
  - **对局外掉血桥接未实装**（见上节「对局外掉血的处理」）。
- 池中遗物（沾血枪尖 / 焚血勋章 / 血仇圣坛）继承 `WandiModRelic`（已带 `[Pool(typeof(WandiModRelicPool))]`），自动入角色遗物池，无需再标 `[Pool]`。

### 纷争 Power（StrifePower）规格（M2.5，与 [卡牌设计·实现备注](万敌Mod-卡牌设计.md) 同源）

- `CustomPowerModel`，`PowerType.Buff` + `PowerStackType.Counter`，层数 = 当前临时生命上限总量（buff 栏直观可见）。
- **获得**：Apply X 层 → `CreatureCmd.SetMaxHp(creature, creature.MaxHp + X)` + `CreatureCmd.Heal(creature, X)`。**不用 `GainMaxHp`**——它会把数值计入地图历史 `MaxHpGained` 永久统计，与永久提升语义冲突（设计红线：临时与永久严格分通道）。
- **上限 clamp（动态算法）**：实际授予层数 = `min(请求值, MaxHp − 2×当前层数)`（余量 = 当前含纷争上限 − 2×已有纷争，等价于「基础最大生命 − 已有纷争」，纷争最多把上限翻倍）。**动态计算而非记录入场值**——战斗中发生永久提升（上限 +N）时基数自动放宽。实现见 [StrifePower.cs:57](../WandiMod/WandiModCode/Powers/StrifePower.cs#L57)。
- **清除**：`AfterCombatEnd` → `SetMaxHp(creature, creature.MaxHp − 层数)`（只扣临时量，战斗中发生的永久提升自然保留）→ 当前生命超出则截断 → 移除自身。
- **结算顺序**：纷争还原截断 → 「不屈」等 AfterCombatEnd 回血（按还原后上限结算）。
- **结算口径**：%MaxHP 纷争来源（如「生命之泉」入场 MaxHp 5%/8%）按**当前含纷争上限**算请求数值，再经动态 clamp 封顶（防自我增殖）；%MaxHP 伤害卡 / 回血（圣坛 / 免死 / 不死王权）也按当前含纷争上限（原生 `MaxHp` 语义，天然联动）。
- 本地化：`powers.json` 加 `StrifePower` 条目；`card_keywords.json` 注册「纷争」词条。

### 免死的 4 次充能

- 弑亲血脉带计数器（初始 4），每次免死 -1；计数器归零后免死失效。
- 遗物计数器 API = `ShowCounter`（bool）+ `DisplayAmount`（int）+ `InvokeDisplayAmountChanged()`（参考原生 PenNib；原生**无** `SetCounter`/`ChangeCounter`）。实现见 [BloodOfTheKinslayer.cs](../WandiMod/WandiModCode/Relics/BloodOfTheKinslayer.cs)。

### 觉醒替换（经欧洛巴斯，不自建 Ancient）

- **无需自建先古之民**。游戏自带的先古之民「欧洛巴斯」会随机给予「欧洛巴斯之触」，其效果是拾起时把当前角色的初始遗物替换为它的**先古（升级）版本**（来源：[杀戮尖塔2中文维基](https://sts2.huijiwiki.com)）。
- 接入方式：在 `BloodOfTheKinslayer` 上重写 `CustomRelicModel.GetUpgradeReplacement()`（见 [CustomRelicModel.cs:13](../BaseLib-StS2/Abstracts/CustomRelicModel.cs#L13)）返回 `UndyingRoyalBlood`。游戏据此把不灭王血识别为弑亲血脉的先古版本，欧洛巴斯之触拾起时自动完成替换。
- `UndyingRoyalBlood` **继承 `BloodOfTheKinslayer`**（从而获得 `WandiModRelic` 的 `[Pool]`）——0.109 起所有遗物模型强制要求 PoolAttribute，缺失会在启动注册时致命崩溃（已踩坑修复）。它不进普通掉落靠的是 `Rarity = Ancient`（仅经欧洛巴斯之触获得），而不是不标 Pool。
- 替换时充能重置为觉醒遗物的满值（6）。具体替换回调（可能需在 `OnObtain` 里把计数器设满）待反编译确认。
