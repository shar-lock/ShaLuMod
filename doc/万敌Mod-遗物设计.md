# 万敌Mod · 遗物设计

> **项目**：Slay the Spire 2 角色模组「万敌（Mydei）」
> **分支**：`wandi`（血仇 + 免死 双核流派）
> **配套**：[万敌Mod-设计方案.md](万敌Mod-设计方案.md) · [万敌Mod-卡牌设计.md](万敌Mod-卡牌设计.md) · [WandiMod-构建验证指南.md](WandiMod-构建验证指南.md)
> **状态**：5 件专属遗物定稿（起手 1 + 普通 1 + 罕见 1 + 稀有 1 + 觉醒起手 1），依赖 M2「血仇」Power 落地
> **图例**：⭐ = 角色灵魂遗物 · 🔁 = 经先古之民「欧洛巴斯」替换起手遗物

---

## 一、设计原则

1. **灵魂遗物先行**：起手遗物「弑亲血脉」合并原方案的**血仇引擎 + 弑亲血脉免死**二为一——它是整个角色的引擎与安全网，让万敌「一上来就玩得像万敌」。
2. **强度随稀有度递增**：普通=被动收益件 / 罕见=流派构建件 / 稀有=核心引擎与终结。每档 1 件。
3. **核心循环闭环**：5 件遗物都挂在「血仇 / 烧血」主轴上，彼此正反馈——起手产血仇、烧血换资源，普通/罕见/稀有逐档把这条链放大，觉醒遗物把它推到高潮。
4. **符合原著**：致敬崩铁「万敌」——毁灭命途、虚数金、血量即资源、天赋级不死、弑神状态。
5. **觉醒=起手的「完全体」**：经游戏自带的先古之民**欧洛巴斯**（拾得「欧洛巴斯之触」时）替换起手遗物；既加数值，也加新机制。

## 三、起手遗物「弑亲血脉」（核心合并）

把设计方案里的 **血仇（Vengeance）Power** 与 **弑亲血脉（4 次免死）** 合并为一件起手遗物。

> **为什么要合并**：血仇是万敌全卡组的资源中枢（誓约之枪 / 蓄势 / 蓄血 / 复仇心 / 弑王枪连突… 都读写它）。若血仇只能靠「血仇形态」形态牌获得，玩家前几层根本凑不出引擎。让**起手遗物自带血仇引擎**，角色从第一场战斗就是万敌；而「血仇形态」形态牌的价值变成「进入血仇强化态（攻击 +25%）」，二者职责分离、互不抢戏。

| 项 | 内容 |
|---|---|
| **名称** | 弑亲血脉 / Blood of the Kinslayer ⭐ |
| **稀有度** | Starter（起手） |
| **流派** | 免死 + 血仇引擎（角色灵魂） |
| **效果** | ① 战斗开始时，获得「血仇」Power。<br>② 每当失去生命（自伤 / 受击 / **对局外事件**，任意来源）→ +1 血仇（对局内由 Power 直接叠层；对局外由遗物暂存，下场战斗开始时转化，详见下文「对局外掉血的处理」）。<br>③ **免死（4 次充能）**：生命值将降至 0 时，免疫死亡，改为回复至 30% 最大生命，消耗 1 次充能（共 4 次）。遗物计数器显示剩余次数。实现套用游戏遗物「蜥蜴尾巴 / Lizard Tail」的免死逻辑。 |
| **致意** | 万敌的弑亲之罪 + 克雷莫诺斯人不死诅咒——他既杀不死，也死不掉。4 次充能致敬星铁天赋「4 次免死」。 |

### 血仇 Power：能做什么

血仇（Vengeance）= `Buff` + `Counter` 计数型 Power。它**不是**纯计数器——层数本身有两类作用：

1. **伤害放大器（被动）**：每层血仇使你的**攻击牌**伤害 **+2%**。失血越多、攻击越狠——这是万敌「越痛越强」的进攻节奏，让起手遗物即便没抽到特定卡牌，攒层也有立竿见影的收益。
2. **卡牌资源**：血仇同时是许多卡牌的燃料——
   - 按层数缩放伤害：`噬仇`（血仇×3 伤）、`狂怒`（造成血仇层数伤）；
   - 消耗层数增伤：`弑王枪·连突`（每段消耗 1 层 +3 伤）、`血祭仪典`；
   - 一次性吞噬爆发：`诛天焚骨的王座`（吞所有血仇，每层全体 8 伤）。

   详见 [卡牌设计稿](万敌Mod-卡牌设计.md)。

> **存与费的抉择**：正因为有被动加成，消耗血仇的卡牌要权衡「现在爆发」还是「保留层数吃 +2%/层」——这是万敌的核心决策张力，避免血仇沦为无脑消耗的数字。

> **强化态归形态牌**：「血仇 ≥ 阈值进入血仇强化态（攻击 +25%）」由**「血仇形态」形态牌**提供，不在基础 Power 内。基础被动（+2%/层）与形态牌强化态（+25%）**叠加**——形态牌是放大这条轴的构建件，而非血仇本身的效果。对应设计方案 4.1 的「①伤害放大器」归基础 Power、「强化态」归形态牌的职责划分。

> **决策记录（已定方案 A）**：血仇基础 Power 保留 **+2%/层攻击伤害**的内在被动。曾考虑纯资源方案（无被动），因起手遗物自洽性更佳、角色进攻节奏更顺而采纳 A。强化态（+25%）仍由「血仇形态」形态牌提供，二者叠加。

### 对局外掉血的处理（遗物桥接）

血仇是**战斗内**的 Power（计数型 buff，仅存在于战斗中）；而捐血 / 献祭类**地图事件**造成的掉血发生在战斗之外，此时血仇 Power 尚未激活。处理方式分两段：

- **对局内掉血**（卡牌自伤 / 受到攻击）：由「血仇」Power 自身的失血回调直接 +1 层（每次掉血事件 +1，非每点生命 +1）。
- **对局外掉血**（地图事件、对局外选项等）：由**遗物本身**（遗物在地图上持久存在）暂存——每次对局外失血，遗物内部计数 +1；**下一场战斗开始时**，遗物把暂存计数一次性转化为血仇（每事件 +1 层，上限 3），随后清零。

> 这样兑现了「只要掉血就是资源」的简化（万敌的伤口在战斗之间也替他蓄力），同时把职责分到正确系统：**Power 管战斗内，遗物管战斗外**。上限 3 防止囤一波事件后开局爆层。
>
> **兜底**：若实装时对局外掉血钩子难以稳定捕获，可直接**忽略**对局外掉血（血仇只在战斗内叠）——核心循环不受影响，是最简退路。

## 四、池中遗物（3 件，每档 1 件）

### 普通

| 遗物（中 / 英） | 效果 | 流派 |
|---|---|---|
| 沾血枪尖 / Bloodied Spearhead | 每当你因**打出的卡牌**失去生命，对所有敌人造成 3 点伤害。 | 烧血·AoE |

> 简单被动收益件——任何烧血牌都顺手触发，不需要特定 build。数值起点，待平衡。
>
> **触发口径**：沾血枪尖与焚血勋章都限定「因**打出的卡牌**失血」才触发（奖励主动烧血的决策）；而起手遗物的血仇引擎是「任意来源失血」（受击也算）。这是有意的区分——挨打不该白送力量 / 全体伤害，但挨打会叠血仇。

### 罕见

| 遗物（中 / 英） | 效果 | 流派 |
|---|---|---|
| 焚血勋章 / Bloodburn Emblem | 每当你因**打出的卡牌**失去生命，获得 1 点力量（本场；本遗物每回合最多提供 3 点力量）。 | 烧血·增益 |

> 「血仇流（卖血）」的核心构建件——把每一次自伤转化为永久（本场）力量，让卖血除了产血仇还能直接变强。封顶 3/回合防雪崩，可调。力量会被多段卡与血仇伤害加成放大，是毁灭命途的力量回路。

### 稀有

| 遗物（中 / 英） | 效果 | 流派 |
|---|---|---|
| 血仇圣坛 / Altar of Vengeance | 每回合开始时，获得 1 血仇。**每当你获得血仇**，对所有敌人造成 2 点伤害。 | 血仇·AoE 引擎 |

> 「血仇流」的终结引擎——**直接吃掉起手遗物产出的血仇**：起手每失一次血 +1 血仇 → 圣坛把它转成全体 2 伤；回合开始还额外白送 1 层。形成「失血 → 血仇 → 全体审判」的正反馈闭环。和「诛天焚骨的王座」「血仇主宰」等吞层数卡牌配合可堆出爆发。

## 五、觉醒起手遗物「不灭王血」（🔁 经欧洛巴斯替换）

| 项 | 内容 |
|---|---|
| **名称** | 不灭王血 / Undying Royal Blood 🔁 ⭐ |
| **稀有度** | Ancient（升级起手；**仅**经欧洛巴斯之触替换弑亲血脉而得，**不进普通遗物池**） |
| **流派** | 免死 + 血仇引擎 + 死亡反击（起手完全体） |
| **替换** | 先古之民「欧洛巴斯」随机给予「欧洛巴斯之触」，拾起时将弑亲血脉替换为本遗物（替换时充能重置为满值）。 |
| **效果** | 继承弑亲血脉全部效果并强化：<br>① **免死强化**：充能次数 4 → **6**；每次回复至 **50%** 最大生命（由 30%）。<br>② **血仇引擎强化**：每次失血获得 **2** 血仇（由 1）；每回合开始额外 **+1** 血仇。<br>③ **新机制「死亡反击」**：免死触发时，吞噬所有血仇，对全体造成（血仇数 × 5）伤害，并回复造成伤害 20% 的生命。 |
| **致意** | 万敌彻底拥抱不死的宿命——死亡本身化作他的武器（致敬星铁终结技「诛天焚骨的王座」的吞层数爆发）。 |

> 觉醒同时满足要求：**加数值**（充能 4→6、30%→50%、1→2 血仇）+ **加新机制**（死亡反击）。死亡反击与血仇圣坛、诛天焚骨的王座等吞层数效果形成流派高潮。

            ┌────────── 弑亲血脉（起手）──────────┐
            │  失血 → +1 血仇          4 次免死兜底  │
            └───────┬───────────────────────┬──────┘
                    │                       │
        ┌───────────▼──────────┐    ┌───────▼────────────┐
        │ 沾血枪尖（普通）      │    │ 焚血勋章（罕见）    │
        │ 失血 → 全体 3 伤      │    │ 失血 → +1 力量      │
        └───────────┬──────────┘    └────────────────────┘
                    │ 血仇
        ┌───────────▼──────────┐
        │ 血仇圣坛（稀有）      │
        │ 血仇 → 全体 2 伤      │
        └───────────┬──────────┘
                    ▼
        ┌── 不灭王血（觉醒·欧洛巴斯）──┐
        │ 产血仇 ×2/回合 +1            │

## 八、实现备注（M2 / M3 实装用）

### 命名 / 资源约定
- 遗物类名 = 英文名 PascalCase，如 `Blood of the Kinslayer` → `BloodOfTheKinslayer`。
- 图标资源 = **类名小写**（见 [WandiModRelic.cs](../WandiMod/WandiModCode/Relics/WandiModRelic.cs) 的 `Id.Entry.RemovePrefix().ToLowerInvariant()` 约定），如 `BloodOfTheKinslayer` → `bloodofthekinslayer.png`，放 `WandiMod/images/relics/` 与 `big/`，外加 `_outline.png`。
- 缺图自动回退 `relic.png` / `relic_outline.png` 占位（M2 先用占位，M4 替换）。

### 依赖与钩子
- **「血仇」Power 是 M2 交付物**，本组所有遗物都依赖它已存在。
- 遗物 / Power 行为钩子来自游戏 `sts2.dll`（BaseLib 的 `CustomRelicModel` / `CustomPowerModel` 仅做薄封装，见 [CustomRelicModel.cs](../BaseLib-StS2/Abstracts/CustomRelicModel.cs)）。精确签名需**反编译**确认（见 wiki `Decompiling.md`），预期用到：
  - **失血回调**：起手血仇引擎（任意来源失血 → +1 血仇）、沾血枪尖 / 焚血勋章（仅「因打出的卡牌失血」→ 效果）。**注意区分触发口径**。
  - **战斗状态判断**：遗物失血回调需判断「当前是否在战斗中」——在战斗内交给血仇 Power 叠层，在战斗外走遗物暂存（见「对局外掉血的处理」）。
  - `AtTurnStart`（血仇圣坛 / 不灭王血）、`AtBattleStart`（遗物把暂存的对局外掉血一次性转化为血仇 + 应用血仇 Power）。
  - **攻击伤害修改回调**：血仇 Power 的被动「每层 +2% 攻击牌伤害」需钩入伤害结算（仅作用于攻击牌伤害，参考原生 `StrengthPower` 的伤害修改写法，反编译确认精确钩子）。
  - **免死**：直接套用游戏遗物「蜥蜴尾巴 / Lizard Tail」的逻辑（生命将降至 0 → 免死并回复 50% 最大生命），反编译 `LizardTail` 拿精确钩子；在其基础上改为「回复 30% + 消耗 1 充能」。
- 池中遗物（沾血枪尖 / 焚血勋章 / 血仇圣坛）继承 `WandiModRelic`（已带 `[Pool(typeof(WandiModRelicPool))]`），自动入角色遗物池，无需再标 `[Pool]`。

### 免死的 4 次充能
- 弑亲血脉带计数器（初始 4），每次免死 -1；计数器归零后免死失效。
- 遗物 counter API（`SetCounter` / `ChangeCounter` 类）需反编译确认精确签名。

### 觉醒替换（经欧洛巴斯，不自建 Ancient）
- **无需自建先古之民**。游戏自带的先古之民「欧洛巴斯」会随机给予「欧洛巴斯之触」，其效果是拾起时把当前角色的初始遗物替换为它的**先古（升级）版本**（来源：[杀戮尖塔2中文维基](https://sts2.huijiwiki.com)）。
- 接入方式：在 `BloodOfTheKinslayer` 上重写 `CustomRelicModel.GetUpgradeReplacement()`（见 [CustomRelicModel.cs:13](../BaseLib-StS2/Abstracts/CustomRelicModel.cs#L13)）返回 `UndyingRoyalBlood`。游戏据此把不灭王血识别为弑亲血脉的先古版本，欧洛巴斯之触拾起时自动完成替换。
- `UndyingRoyalBlood` **不继承 `WandiModRelic`、不标 `[Pool]`**——避免它出现在普通遗物掉落里；它只能经欧洛巴斯替换获得。直接继承 `CustomRelicModel` 即可。
- 替换时充能重置为觉醒遗物的满值（6）。具体替换回调（可能需在 `OnObtain` 里把计数器设满）待反编译确认。

### 本地化
- 5 件遗物 → `WandiMod/localization/eng/relics.json`。
- **无需** `ancients.json`（欧洛巴斯是游戏自带先古之民，不在本 mod 内）。
- 用 Rider「Generate localization」代码修正生成骨架，再填文案（流程同卡牌，见 [Adding-Cards.md](../ModTemplate-StS2.wiki/Adding-Cards.md) 的 Localization 节）。

### 待核实项（实装时确认）
- **免死钩子**：反编译「蜥蜴尾巴 / Lizard Tail」拿到「生命将降至 0」的精确回调与回复机制，在其上加充能计数（4 次 / 觉醒 6 次、回复比例 30% / 50%）。
- **失血回调**：找到一个「角色失去生命」时触发的钩子，确认它是否同时在战斗内 / 战斗外触发，以及如何区分来源（卡牌效果 vs 受击）——决定沾血枪尖 / 焚血勋章的口径判定写在哪。
- **战斗状态判断**：确认判断「当前是否在战斗中」的 API（用于遗物桥接对局外掉血）。
- `GetUpgradeReplacement()` 是否就是欧洛巴斯之触查询升级目标的入口——若是则零成本接入；否则按反编译结果调整注册方式。
- 数值均为起点，用 dev console 在游戏内迭代平衡。
