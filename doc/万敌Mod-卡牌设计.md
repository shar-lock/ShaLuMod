# 万敌Mod · 卡牌设计

> **项目**：Slay the Spire 2 角色模组「万敌（Mydei）」  
> **分支**：`wandi`（血仇 + 免死 双核流派）  
> **配套**：[万敌Mod-设计方案.md](万敌Mod-设计方案.md) · [WandiMod-构建验证指南.md](WandiMod-构建验证指南.md)  
> **状态**：85 张完整设计稿，待 M3 实装 + 数值平衡迭代  
> **图例**：⭐ = 角色灵魂卡 · 🔗 = 联机卡

## 一、稀有度与术语（按游戏内描述）

| 中文 | 英文 | 卡背 | 定位 |
|---|---|---|---|
| 普通 | Common | — | 万用基础件，独立可用 |
| 罕见 | Uncommon | 蓝 | 流派构建件，定义 build |
| 稀有 | Rare | 金 | 核心引擎 + 终结技，强度最高 |

> 顺序：**普通 < 罕见（蓝） < 稀有（金）**。

---

## 二、设计原则

1. **类型平衡**：攻击 / 技能 / 能力 ≈ 36 / 33 / 16。
2. **攻防平衡**：攻击牌 36；提供格挡/回血/减益的牌约 30（攻防比 1:0.85，偏进攻但防御充足，符合毁灭命途）。
3. **符合万敌**：失血即资源、免死兜底、生命倍率、扩散多段、金色/枪。
4. **强度随稀有度递增，低稀有也有用**：普通全是独立可用的过牌/格挡/失血增益件。
5. **多流派可混搭**：五系在每档稀有度都有支撑。

---

## 三、五大流派（多流派自由组合）

| 流派 | 核心思路 | 关键机制 |
|---|---|---|
| 🩸 血仇流 | 叠血仇 → 转化力量 / 吞噬爆发 | 血仇计数、消耗层数增伤 |
| 🔥 烧血流 | 自伤换高收益（血量即资源） | 失去生命触发强力效果 |
| 💀 残血流 | 越残血越强，免死兜底 | HP 低于阈值时强化 |
| 🟡 生命倍率流 | 按「最大生命」缩放伤害/格挡 + 回血续航 | 坦克型狂战 |
| ⚔️ 扩散多段流 | 多段连击 + 单体溅射全体 + 持续伤害 | 多段、AoE、流血 |

**流派交织**：烧血 → 触发血仇叠层 + 压低血线 → 残血流强化 + 免死兜底 → 吞噬血仇终结。

## 五、特殊机制约定

### X 费（吞能连发，集中在稀有）
X = 消耗全部当前能量，按能量数发动 X 次。共 3 张：
- `弑神枪·无尽`（攻击 X）：5 伤 × X 次。
- `金色壁垒`（技能 X）：X×5 格挡，本回合 +X 力量。
- `血祭仪典`（技能 X）：失 X×2 血，抽 X 牌，获得 X 血仇。

### 联机卡（5 张：3 罕见 + 2 稀有）
怪物每回合攻击所有玩家，**嘲讽无效**。联机卡走两条线：
- **承伤型**：替队友承担/转移伤害（万敌靠免死活下来）。
- **全体增益型**：给所有队友力量 / 格挡 / 治疗。

### 减益与增益
- 敌方减益：易伤（Vulnerable）、虚弱（Weak）、**流血（Bleed，本 mod 新增持续伤害）**。
- 自身增益：力量（Strength）、血仇、回血。
- 「流血」实现时确认是否对接 StS2 原生 debuff，否则作为自定义 Power。

## 十一、实现备注（M3 实装用）

### 命名 / 资源约定
- 卡牌类名 = 英文名的 PascalCase，如 `Blood Rite` → `BloodRite`。
- 卡面资源 = 小写下划线，如 `BloodRite` → `blood_ride.png`（放 `WandiMod/images/card_portraits/` 与 `big/`），对应模板 `Id.Entry.RemovePrefix().ToLowerInvariant()` 约定。
- 缺图自动回退 `card.png` 占位（M3 可先用占位图，M4 替换）。

### 本地化
- `WandiMod/localization/eng/cards.json` 存放卡牌文案；中英文显示名见上表「中 / 英」列。
- 实装时用 Rider 的「Generate localization」代码修正生成骨架，再填入文案。

### 待核实项（实装时确认）
- StS2 是否有原生「流血 / 持续伤害」debuff，决定「流血」是复用还是自定义 Power。
- 自伤、致死免死、X 费吞能等高级效果的具体钩子（可能需 Harmony），见 [Accessing-private-class-members-(Reflection).md](../ModTemplate-StS2.wiki/Accessing-private-class-members-(Reflection).md) 与 [Common-Commands-Cookbook.md](../ModTemplate-StS2.wiki/Common-Commands-Cookbook.md)。
- 数值均为起点，需用 dev console 在游戏内迭代平衡。
