# 万敌Mod · 卡牌设计（v3 · 纷争机制 · 三流派互联）

> **项目**：Slay the Spire 2 角色模组「万敌（Mydei）」
> **分支**：`wandi`
> **配套**：[万敌Mod-设计方案.md](万敌Mod-设计方案.md) · [万敌Mod-遗物设计.md](万敌Mod-遗物设计.md) · [WandiMod-构建验证指南.md](WandiMod-构建验证指南.md)
> **状态**：v3 重订稿。**【纷争】（临时生命上限）全面取代格挡**——万敌不再获得格挡，所有防御牌改为获得纷争；「纷争形态」更名「**力敌万邦**」（血仇引擎效果不变）；原「命途流」升级为「纷争流」。共 86 张 = **机制卡 1（荡平万邦，由弑亲血脉生成）+ 普通 20（含起手）+ 罕见 38（含 3 联机）+ 稀有 27（含 2 联机）**。

## 二、设计原则

1. **三流派互联，不割裂**：所有流派共享「血仇 + 生命经济」，一张牌的副产品是另一张的燃料。
2. **机制不撞原版**：独占原版空白——玩家自身失血计数（血仇）、「已损失生命」缩放、HP 阈值触发、玩家自身最大生命缩放、**玩家临时生命上限（纷争）**。
3. **数值对齐原版**：伤害/纷争/升级幅度严格参考 580 张实测区间（见第十节）。
4. **尊重原版禁区**：直接回血极度稀缺（默认耗尽且 ≤10）；**永久**最大生命提升受限（仅 Rare 耗尽）；临时上限一律走【纷争】体系（积累上限 = 入场最大生命 ×100%，战斗结束清空）。
5. **符合星铁万敌**：失血即资源、天赋免死、虚数金、枪。

## 三、三大流派与互联

| 流派                           | 在循环里的角色                                                                   | 独占创新轴（原版 0 命中）   |
| ------------------------------ | -------------------------------------------------------------------------------- | --------------------------- |
| 🩸**血仇流**（卖血核心） | 自伤/受击→产血仇；持有加伤害，消耗打爆发；自伤压低血线                          | 玩家自身失血计数器          |
| 💀**残血流**             | 在低血线上触发质变                                                               | HP 阈值触发（<50% / ≤30%） |
| 🟡**纷争流**（防御核心） | 【纷争】临时生命上限作防御（**无格挡**）；膨胀的 MaxHP 作伤害/防御缩放基底 | 玩家临时 MaxHP、无格挡防御  |

**血仇（Vengeance）**：`Buff` + `Counter` 计数型 Power。来源——自伤、受击、专用产层卡。持有时每层 +2% 攻击伤害（由起手遗物「弑亲血脉」战斗开始赋予该 Power）；可被多张牌消耗换爆发。「已损失生命」（MissingHp）随卖血自然累积，是缩放基底。

**【纷争】（Strife）**：`Buff` + `Counter` 计数型 Power，层数 = 当前临时生命上限总量。获得 X 纷争 = 最大生命 +X 并回复 X（抬上限 + 等量回血）；积累上限 = **入场最大生命 ×100%**（入场值含永久提升）；**战斗结束清空**，上限仅扣减纷争累计值、当前血量超出则截断，与永久提升严格分通道。它是万敌唯一的"防御"——他不格挡，他用更多的血硬扛。

- **协同**：%MaxHP 伤害卡（金色裁决/命途斩）按**含纷争的当前上限**结算——纷争放大进攻；获得纷争 = 回血事件 → 触发焚血勋章；MissingHp 分子分母同加不变 → 不稀释 MissingHp 缩放。
- **防滚雪球**：%MaxHP 的**纷争来源**（绝对防御/生命之泉）一律按**入场最大生命**结算，纷争不能自我增殖。
- **张力**：纷争把血量比拉向 100%，会**脱离残血阈值**——堆纷争稳守 vs 压血线赌残血，是攻守两端的抉择。

**互联循环**：

```
纷争流 → 临时上限扛伤 + 放大 MaxHP 缩放，给卖血预算
              ↓
血仇流 → 自伤/受击产「血仇」+ 压低「HP」
        ↙ 血仇                ↘ 低 HP
   消耗爆发                    残血流触发
        ↖  ← 力量/血仇联动   ↗
          （免死遗物兜底全程）
```

## 十、联机卡说明（5 张：3 罕见 + 2 稀有）

联机模式下怪物每回合攻击**所有**玩家，且**嘲讽无效**。万敌的联机卡走两条线，均围绕「免死 + 卖血」身份：

> **格挡口径**：万敌自身不产出格挡（全部改为纷争）；但联机卡中**给予队友**的防御（王者之佑、替天行道）仍是原版「格挡」——队友没有【纷争】机制，不入侵队友的结算体系。

- **承伤型**（庇护盟约 / 替天行道 / 以血还血）：替队友承担/转移伤害，靠免死活下来；以血还血还能把承伤转化为反击。
- **全体增益型**（同仇敌忾 / 王者之佑）：给所有队友力量 / 格挡。

## 十一、数值校准规则（原版 580 卡实测，已遵循）

- **伤害/费**（单体纯伤）：0c≈6、1c≈8-10、2c≈15-18、3c≈24-32。
- **纷争/费**（原格挡位）：0c≈4-7、1c≈5-9、2c≈11-16（2 费大额 30 须耗尽）。数值沿用格挡区间起步——纷争跨回合留存且放大 MaxHP 缩放（偏强），但受 100% 积累上限与残血反协同约束，强弱待实测迭代。
- **升级**：伤害/纷争默认 **+3**；低基础（多段）+1/+2；大招 +5~+8；3 费形态牌走**降费 -1**。
- **耗尽预算**：带 Exhaust 数值可 +30-50%。
- **自伤预算**：每失 1 血 ≈ +2-4 数值或换 1 抽/1 能量。
- **多段**：单段 = 同档位单体的 40-60%。
- **回血禁区**：直接回血默认耗尽且 ≤10；本组用「攻击吸血 / 耗尽小额 / 耗尽比例」三类合规形式。
- **最大生命+N（永久）**：限 Rare 且耗尽，单次 +3~8（对齐原版 Feed +3 耗尽）；永久提升抬「入场基数」，纷争 100% 上限随之上浮。临时上限一律走【纷争】体系，卡牌文案不写"本场 +N 上限"的自由形式。

## 十三、实现备注（M3 实装用）

### 命名 / 资源

- 卡牌类名 = 英文名 PascalCase（`Blood Rite` → `BloodRite`）。
- 卡面资源 = 类名小写（`Id.Entry.RemovePrefix().ToLowerInvariant()`），放 `WandiMod/images/card_portraits/` 与 `big/`；缺图回退 `card.png` 占位。

### 机制实装钩子（均已反编译确认，见 `_src/sts2_src`）

- **血仇 Power**：`CustomPowerModel`，`Buff + Counter`；伤害放大走 `ModifyDamageMultiplicative`（参考 `WeakPower`）；失血叠层走 `AfterDamageReceived`（参考 `RupturePower`）。
- **纷争 Power（StrifePower）**：`CustomPowerModel`，`Buff + Counter`，层数 = 当前临时上限总量。获得 X 层 → `CreatureCmd.SetMaxHp(creature, MaxHp + X)` + `CreatureCmd.Heal(creature, X)`（**不用** `GainMaxHp`——它会把数值计入地图历史 `MaxHpGained` 永久统计，必须和永久提升隔离）；Apply 时 clamp 到「入场 MaxHP ×100% − 当前层数」。`AfterCombatEnd` → `SetMaxHp(当前 MaxHP − 层数)`（只扣临时量，战斗中发生的永久提升自然保留）+ 当前血超出则截断 + 移除自身。%纷争来源按入场值结算（Power 建立 / 战斗开始时记录 `entryMaxHp`）。
- **自伤**：`CreatureCmd.Damage` 对自己；**免死**：`ShouldDieLate` + `AfterPreventingDeath`（参考 `LizardTail`）。
- **MissingHp / MaxHp**：`creature.CurrentHp` / `creature.MaxHp`。
- **回合钩子**：`AfterSideTurnStart`；「格挡被击破」触发待确认精确 hook（浴血奋战）。

### 本地化

- `WandiMod/localization/eng/cards.json`；Rider「Generate localization」生成骨架后填文案。
- 「纷争」需在 `card_keywords.json` 注册词条（卡牌描述里大量引用），`powers.json` 加 `StrifePower` 条目。
- 占位符参考原版：`{Damage:diff()}`、`{VengeancePower:diff()}` 等；纷争数值用 `{StrifePower:diff()}`。
- **待办：补** `localization/zhs/*.json`——当前仅 eng，中文客户端全部回退英文显示。

### 待核实项

- 「格挡被击破」事件的精确回调（浴血奋战，针对**敌方**格挡）——反编译 `CreatureCmd` 格挡结算路径确认。
- 「HP 阈值」是动态判定（每张牌 OnPlay 读 `CurrentHp/MaxHp`），无需专门 hook。
- 纷争 Power：`entryMaxHp` 记录时点（`BeforeCombatStart` vs 首次 Apply 时）；战斗结束结算顺序——先纷争还原截断，再执行「不屈」等 AfterCombatEnd 回血（按还原后上限结算）。
- 数值均为起点，用 dev console 在游戏内迭代平衡。
