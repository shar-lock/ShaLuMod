## 一、项目概述

把星铁「万敌」（毁灭命途 · 虚数属性 · 五星）的战斗风味移植为 StS2 的原创角色模组。核心体验：**越死越强，且死不掉**——主动卖血叠「血仇」计数，压低血线换取爆发，靠天赋级「免死」兜底，敢于刀尖舔血。**万敌没有格挡**——他的防御是【纷争】：战斗内临时抬高生命上限并回等量血，用「更多的血」硬扛伤害，战斗结束后纷争清空、上限还原。他不防守，他硬扛。

> ⚠️ 数值均为**待平衡的起点**，需进游戏后用 dev console 迭代。

## 四、核心机制与三流派

### 4.1 三流派互联（不割裂）

所有流派共享「血仇 + 生命经济」，一张牌的副产品是另一张的燃料：

| 流派                           | 角色                                                | 独占轴          |
| ------------------------------ | --------------------------------------------------- | --------------- |
| 🩸**血仇流**（卖血核心） | 自伤/受击→产血仇；持有加伤、消耗爆发；自伤压低血线 | 失血计数器      |
| 💀**残血流**             | 在血仇流压出的低血线上触发质变                      | HP 阈值触发     |
| 🟡**纷争流**（防御核心） | 【纷争】临时生命上限作防御（无格挡）；放大的 MaxHP 作伤害/防御缩放基底 | 玩家临时 MaxHP、无格挡防御 |

> 循环：纷争流抬临时上限扛伤 + 放大 MaxHP 缩放 → 血仇流卖血产血仇 + 压低 HP → 消耗爆发 / 残血流触发。免死遗物贯穿全程兜底。
> ⚠️ 张力：纷争抬血线（分子分母同加，血量比向 100% 靠拢）会**脱离残血阈值**——「堆纷争稳守」与「压血线赌残血」是攻守两端的抉择，不是无脑全都要。

### 4.2 血仇（Vengeance）—— 计数型 Power

- `PowerType = Buff`，`PowerStackType = Counter`。
- **触发**：每当失去生命（自伤或受击）→ `+1` 层。
- **双重作用**：①**伤害放大器**——每层 +2% 攻击伤害（被动，由起手遗物在战斗开始赋予该 Power）；②**卡牌资源**——多张牌消耗层数换爆发（弑王枪连突、诛天焚骨的王座等）。
- **强化态**：由「力敌万邦」（原纷争形态）形态牌提供（回合加速产层 + 抽牌），与基础被动叠加。
- **实现钩子**（已反编译确认）：失血叠层 `AfterDamageReceived`（参考 `RupturePower`）；伤害放大 `ModifyDamageMultiplicative`（参考 `WeakPower`）。

### 4.3 弑亲血脉 —— 起手遗物（4 次免死 + 血仇引擎）

- **效果**：战斗开始赋予「血仇」Power；每次失血 +1 血仇；**血仇积累到 7 层时，消耗 7 层、扣除当前血量 5%（至少为 1），将一张「荡平万邦」无色卡加入手牌**；受到致命伤害时免死，回复至 30% 最大生命，消耗 1 次充能（共 4 次）。
- **定位**：整套卖血玩法的引擎 + 兜底，角色灵魂一件到位。
- **实现**：免死套用 `ShouldDieLate` + `AfterPreventingDeath`（参考 `LizardTail`，**已确认可行，不再是高风险项**）；觉醒版「不灭王血」经欧洛巴斯之触替换（`GetUpgradeReplacement()`，已确认）。

> 这套机制让万敌**玩起来像万敌**（毁灭 + 不死），而不是又一个数值怪。详见 [遗物设计](万敌Mod-遗物设计.md)。

### 4.4 【纷争】—— 临时生命上限（无格挡防御体系）

万敌**不会获得格挡**。所有原本产出格挡的牌（含起手「防御」位）全部改为产出【纷争】：

- **定义**：纷争 = 战斗内临时生命上限。获得 X 点纷争 → 最大生命 **+X** 并**回复 X 点生命**（语义与 `CreatureCmd.GainMaxHp` 一致：抬上限 + 等量回血）。
- **积累上限**：当场战斗累计纷争 **≤ 入场最大生命 × 100%**（入场值 = 含永久提升后的最大生命）。即有效生命上限最高**翻倍**。
- **清除**：战斗结束时清空全部纷争——最大生命**仅扣减纷争累计值**（战斗中若发生永久提升，永久部分保留），当前生命超出还原后上限则截断。**纷争不跨战斗保留**。
- **与永久提升的区分**（关键约束）：
  - 永久提升（仅「涅槃重生」等极少数 Rare·耗尽件）抬的是**入场基数**，会让下一场战斗的纷争上限水涨船高；纷争只是临时膨胀，二者结算通道完全分开。
  - 实现上纷争**不走** `GainMaxHp`（它会把数值计入地图历史 `MaxHpGained` 永久统计），改用 `SetMaxHp` + `Heal` 手动组合，保证统计与语义都和永久提升隔离。
- **结算规则**（防滚雪球）：
  - 所有 **%最大生命** 的**纷争来源**（绝对防御、生命之泉等）按**入场最大生命**结算，不按膨胀后上限——纷争不能自我增殖。
  - 所有 **%最大生命** 的**伤害**卡（金色裁决、命途斩）按**当前最大生命（含纷争）**结算——纷争放大进攻缩放。攻守不对称是刻意设计。
  - %最大生命 的**回血**（血仇圣坛、不死王权、免死回复 30%）按当前含纷争上限结算（游戏原生 `creature.MaxHp` 自然如此）。
- **联动**：获得纷争 = 一次回血事件 → 触发「焚血勋章」（回血 → +1 血仇）；获得纷争不改变 MissingHp（分子分母同加）→ 不稀释 MissingHp 缩放卡。
- **实现**：计数型 Power「纷争 / Strife」（`Buff + Counter`，层数 = 当前临时上限总量，buff 栏直观可见）。规格详见 [遗物设计 · 实现备注](万敌Mod-遗物设计.md)。

## 八、平衡原则

**高风险高收益**：血量即资源，越残血越强，爆发极高；容错由「免死」撑。避免做成无脑强——每次卖血都应是**有代价的决策**。数值锚点对齐原版 580 卡实测（见卡牌设计稿第十节）。
